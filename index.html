What we’re asking for

Plan it first

There is no plan for 300 of the 460 acres. The other 160 acres was not planned for industrial at all. The master plan says you can’t change land until you first plan it.

Define it in the code

Explicitly define whether data centers are included in Gardner’s code and M-1.
